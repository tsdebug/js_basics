# js_basics
Type of lanuguages - 'Static Languages' and 'Dynamic Languages' <br>
JavaScript is a dynamic language.<br>
While the HTML gives structure and CSS gives style, JavaScript gives logic as to how the webpage should work, to make it interactive and dynamic instead of just a static page.<br>
Types of literals - 'Primitive Literals' (Strings, Numbers, Booleans, Undefined, Null) & 'Relational Literals' (Object, Array, Function)
